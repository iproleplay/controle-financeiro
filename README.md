# 💳 FinancePro

Sistema financeiro web desenvolvido com Flask, com dashboard moderno estilo banco digital.

---

## 🚀 Tecnologias Utilizadas

- Python 3
- Flask
- SQLite
- Chart.js
- HTML5 + CSS3
- Gunicorn (produção)

---

## 📊 Funcionalidades

✔ Cadastro e login de usuários  
✔ Controle de renda mensal  
✔ Registro de contas fixas e variáveis  
✔ Meta de gastos percentual  
✔ Barra de progresso da meta  
✔ Filtro por mês e ano  
✔ Gráfico por categoria  
✔ Gráfico fixo x variável  
✔ Evolução mensal  
✔ Área administrativa  
✔ Layout moderno estilo fintech
